\## 배운 것

\- Scanner: nextLine()은 Enter까지 한 줄, nextInt()는 숫자 하나

\- nextInt()는 Enter를 남겨둔다 → 바로 다음에 sc.nextLine()으로 치워야 제목 입력이 안 건너뛰어진다

\- while(true) + switch로 메뉴 반복, 0번은 return으로 main 자체를 끝냄

\- switch 안의 break는 switch만 빠져나오고 while은 계속 돈다

\- case 끝에 break/continue가 없으면 아래 case로 흘러내린다 (fall-through)

\- 같은 { } 안에서 같은 이름의 변수를 두 번 선언할 수 없다 → title을 switch 밖에서 한 번만 선언

\- try-catch: try는 에러가 나는 줄을 감싼다. 예외가 나면 try 나머지는 건너뛰고 catch로 점프

\- 에러 읽기: 예외 이름(InputMismatchException) → 내 패키지 이름 있는 줄의 줄 번호



\## 헷갈린 것

\- 번호 자리에 제목을 쳐서 InputMismatchException으로 프로그램이 죽음

\- 처음에 try로 메뉴 출력 줄을 감쌌음 → println은 에러가 안 나니 소용없음

\- num을 0으로 초기화했더니 abc 입력 시 catch 후 case 0으로 내려가서 "종료합니다"가 나옴

&#x20; → catch 안에서 sc.nextLine()으로 abc 치우고 continue로 메뉴로 돌아가기

\- case 4에 continue를 빼먹어서 책 등록 후 프로그램이 종료됨 (fall-through)



abc를 넣었는데 왜 "종료합니다"가 나왔지? - catch 후 case 0 으로 내려가서 종료합니다가 나온다. 

try는 어느 줄을 감싸야 하지? - println은 에러가 안남 그렇기 때문에 기본적인 출력문을 적는다.

case 4에서 등록 후 프로그램이 꺼진 이유는? - continue를 빼먹어서 프로그램이 종료됨
