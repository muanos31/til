# 2026-11-05 (1단계: ArrayList와 Library)

## 배운 것
- ArrayList: 크기가 자동으로 늘어나는 리스트. add(추가), get(번호), size(개수)
- 배열은 크기 고정, ArrayList는 계속 추가 가능
- Library 구조: Main(손님) → Library(창구) → ArrayList(책장) → Item(책)
- Main은 책장을 직접 건드리지 않고 lib.borrow("제목")처럼 창구에 제목만 넘긴다 (캡슐화)
- 문자열 비교는 == 말고 .equals()
- findByTitle: for문으로 하나씩 보다가 찾으면 return item, 끝까지 없으면 return null
- borrow(제목): findByTitle로 찾고 → null이면 "찾을 수 없음" → 있으면 그 책의 borrow()
- 객체를 그냥 println하면 클래스이름@주소가 찍힌다 → getTitle()로 꺼내기

## 헷갈린 것
- for문 안에 return null을 넣으면 첫 번째 책만 보고 메서드가 끝나버림
  → return은 반복문 중간이라도 즉시 메서드를 끝낸다
- Library를 여러 개 담는 ArrayList<Library>를 만들었음 → 도서관은 하나, 책은 addItem으로
- returnItem을 borrow에서 복붙하고 마지막 줄 found.borrow()를 안 바꿔서 반납이 안 됨
- 메서드 이름 printall / printAll / prinAll → 철자, 대소문자까지 똑같아야 함
